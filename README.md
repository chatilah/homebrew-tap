# homebrew-tap

Homebrew formula tap for [KeePass TUI](https://github.com/chatilah/keepass-tui).

Install KeePass TUI with:

```sh
brew install chatilah/tap/keepass-tui
```

The formula downloads the checksum-verified macOS binary from the matching
GitHub release. New releases are published to this tap by the
`keepass-tui` repository's release workflow, which requires a
`HOMEBREW_TAP_TOKEN` Actions secret with write access to this repository.
